# demo-html

Vanilla HTML/TypeScript demo for [`@starfleet-technology/lcars`](../../packages/lcars).

Loads LCARS web components via the Stencil loader and renders them directly in HTML — no framework required.

## 🚀 Run locally

```bash
# from the monorepo root
pnpm dev --filter="@starfleet-technology/demo-lcars-html"
```

Opens at **http://localhost:5173**

```bash
# build & preview
pnpm build --filter="@starfleet-technology/demo-lcars-html"
pnpm preview --filter="@starfleet-technology/demo-lcars-html"
```
