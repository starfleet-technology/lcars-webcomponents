# demo-react

React 19 + Vite demo for [`@starfleet-technology/lcars-react`](../../packages/lcars-react).

Shows LCARS components used as standard React components via the Stencil React output target.

## 🚀 Run locally

```bash
# from the monorepo root
pnpm dev --filter="@starfleet-technology/demo-lcars-react"
```

Opens at **http://localhost:5174**

```bash
# build & preview
pnpm build --filter="@starfleet-technology/demo-lcars-react"
pnpm preview --filter="@starfleet-technology/demo-lcars-react"
```
