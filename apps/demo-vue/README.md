# demo-vue

Vue 3 + Vite demo for [`@starfleet-technology/lcars-vue`](../../packages/lcars-vue).

Shows LCARS components used as Vue components via the Stencil Vue output target.

## 🚀 Run locally

```bash
# from the monorepo root
pnpm dev --filter="@starfleet-technology/demo-lcars-vue"
```

Opens at **http://localhost:5175**

```bash
# build & preview
pnpm build --filter="@starfleet-technology/demo-lcars-vue"
pnpm preview --filter="@starfleet-technology/demo-lcars-vue"
```
