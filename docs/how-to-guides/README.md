# How-to Guides

**Problem-oriented practical guides**

How-to guides are step-by-step instructions for solving specific, real-world problems. They assume the reader has some basic knowledge and wants to accomplish a particular task.

## How-to Guide Characteristics

- **Problem-oriented**: Address specific issues or tasks
- **Practical**: Focus on doing, not explaining
- **Goal-oriented**: Help achieve a specific outcome
- **Flexible**: Can be adapted to different scenarios
- **Reliable**: Tested solutions that work

## Content Guidelines

- Start with a clear problem statement
- Provide tested, working solutions
- Focus on the steps needed to solve the problem
- Assume basic knowledge of LCARS components
- Link to relevant reference documentation
- Keep explanations brief and focused on the task
