# Reference

**Information-oriented technical documentation**

Reference documentation provides comprehensive technical information about LCARS components, APIs, and configurations. It's the authoritative source for precise details.

## Reference Characteristics

- **Information-oriented**: Factual, technical details
- **Comprehensive**: Complete coverage of features
- **Precise**: Accurate and up-to-date information
- **Structured**: Organized for easy lookup
- **Authoritative**: The definitive source of truth

## Content Guidelines

- Use consistent formatting and structure
- Provide complete API documentation
- Include all parameters, properties, and methods
- Show type information and examples
- Keep descriptions factual and concise
- Organize information logically
- Update documentation with code changes
