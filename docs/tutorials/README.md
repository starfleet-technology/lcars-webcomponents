# Tutorials

**Learning-oriented content for beginners**

Tutorials are step-by-step lessons that take learners by the hand through a series of exercises to complete a project. They are what your project needs in order to show a beginner that they can achieve something with it.

## Tutorial Characteristics

- **Learning-oriented**: Focus on acquiring skills and understanding
- **Practical**: Learners should get their hands dirty
- **Concrete**: Real, practical examples and projects
- **Inspiring**: Show what's possible with LCARS components
- **Safe to follow**: Reliable, tested steps that work

## Content Guidelines

- Start with the simplest possible working example
- Use specific, concrete examples rather than abstract concepts
- Ensure each step can be completed successfully
- Test tutorials regularly to ensure they still work
- Provide complete, working code examples
- Focus on doing, not explaining theory
