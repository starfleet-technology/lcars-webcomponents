# @starfleet-technology/lcars

## 0.0.5

### Patch Changes

- 7a8f9b6: Remove Stencil scaffold `my-component` from the public API.

  `my-component` was the default component generated by `stencil generate` and was never part of the LCARS design system. It has been deleted from the core package and its bindings have been removed from the React and Vue wrapper packages.

  **Breaking changes:**

  - `@starfleet-technology/lcars`: the `./my-component` subpath export has been removed
  - `@starfleet-technology/lcars-react`: `MyComponent` is no longer exported
  - `@starfleet-technology/lcars-vue`: `MyComponent` is no longer exported

  Additionally, the internal `format` string utility is no longer re-exported from `@starfleet-technology/lcars`'s package entry point — it was never intended as public API.
